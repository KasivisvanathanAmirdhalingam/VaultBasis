A0. macOS treats the file as a Document — "no application to open"

Do not use "Choose Application" to force it to run. A file macOS cannot recognize as an application is not a qualified VaultBasis installer. Forcing it open is not the practitioner journey and may leave your machine in an unknown state.

Stop here and reply to your download email with a screenshot. You have encountered a packaging defect: the distributed file is not a launchable macOS application. Your files have not been changed.

A. macOS — security message on first launch

This preview build is distributed outside the Mac App Store and is not yet Apple-notarized. macOS Gatekeeper will block it the first time. That block is expected.

All supported macOS versions (13 Ventura, 14 Sonoma, 15 Sequoia)

  1. Double-click VaultBasis.app in Finder. macOS will show a security dialog — click Done.
  2. Open System Settings → Privacy & Security and scroll down to the Security section.
  3. You will see a message that VaultBasis was blocked. Click Open Anyway.
  4. Enter your Mac password if asked. You only do this once — macOS remembers.

After clicking Open Anyway, double-click VaultBasis.app again and it will open normally.

B. VaultBasis starts but the browser does not open

The current preview build does not auto-open the browser on all machines. This is a known preview limitation, not a failure.

  1. Leave the black terminal window open.
  2. Open Chrome, Safari, or Edge manually.
  3. Type this address exactly:
http://127.0.0.1:8000

If the dashboard loads, continue with your case. No further fix is needed.

C. Browser says "cannot connect" or "refused to connect"

  1. Check the black terminal window is still open. If it is closed, restart VaultBasis.
  2. Wait 5 seconds after launch, then refresh the browser.
  3. If another program already uses port 8000, quit that program and restart VaultBasis.
  4. Try a different browser (Chrome → Safari, or Safari → Chrome).
What this address means: 127.0.0.1:8000 is your own computer talking to itself. Nothing is sent over the internet. If your firewall asks, allow local connections only.

D. Windows — "Windows protected your PC" blue screen

Status: The Windows build is still under qualification. Only follow this section if you were explicitly given a Windows installer. The macOS file does not run on Windows.
  1. Click the underlined "More info" text.
  2. Click "Run anyway" at the bottom.
  3. Click Yes if Windows asks for permission.

You only do this once. If Windows still blocks it after these steps, stop and reply to your download email — do not disable SmartScreen or antivirus globally.

E. Receipt will not download or will not verify

  1. A receipt is only produced after a reconciliation run completes. Run "Run Deterministic Reconciliation" first, then open the Receipt screen.
  2. The Evidence Bundle (.zip) contains the signed receipt, the source files you uploaded, the schema, and an offline verifier. All four must stay together for independent verification.
  3. To verify on a clean machine, use the included verify_receipt.py or the web verifier — no VaultBasis account or network connection is required.
What the signature means — and does not mean: The signature proves the receipt content has not been altered since it was signed by your local installation key, under the verification scheme in the bundle. It does not by itself prove where the software was run, and it does not determine tax or legal compliance. VaultBasis reports what matches, what differs, and what is unresolved. Your reviewer makes the compliance determination.

Advanced — if Open Anyway does not appear (macOS, technical support)

Only use this if System Settings → Privacy & Security does not show an Open Anyway button after the first blocked launch attempt.

Advanced diagnostics (for technical support)
  1. Open Terminal (press ⌘ Space, type Terminal, press Enter).
  2. Paste the following line, then press Enter. Enter your Mac password when asked (nothing appears while typing — that is normal):
$ xattr -d com.apple.quarantine ~/Downloads/VaultBasis.app

If you see No such xattr, the flag is already cleared — skip ahead.

  1. Double-click VaultBasis.app in Finder. It will launch.
Different folder? Replace ~/Downloads/ with the path to wherever VaultBasis.app is located. Tip: drag the app from Finder into the Terminal window to paste its path automatically.
