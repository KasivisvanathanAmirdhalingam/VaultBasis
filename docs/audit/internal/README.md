# Internal audit working index

Audience: internal engineering/release review. Update every task under [VB-GOV-001](../../task_execution_standard.md). Repository visibility/access enforcement must be handled by its owner; this directory name is not a security control.

| Record | Purpose |
|---|---|
| [Task registry](../../task_registry.json) | Stable ID, current state, full implementation SHAs, closeout and documentation dispositions |
| [Task closeouts](tasks) | Per-task requirement, change, verification, documentation impact and limitations |
| [Current status](../../status.md) | Actual next gates, blockers and no false qualification |
| [Traceability](../traceability-matrix.md) | Protected truth, founder evidence, history and verification side by side |
| [Development workflow](../../development_workflow.md) | Exact branch/CI/preview/native/promotion controls |

Keep sensitive evidence in approved controlled storage, referenced by identifier/digest/access owner. No credentials, private keys or taxpayer records in the repository. External-ready summaries are maintained [separately](../external/README.md) and require authorization before publication.
