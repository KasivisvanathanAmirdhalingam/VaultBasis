Help & Getting Started

Guidance for using VaultBasis Edge locally.

Getting Started

  1. Click + New Case and enter a case identifier.
  2. Open the case, then upload your source files (Form 1099-DA CSV/JSON, Koinly CSV).
  3. Click ⚡ Run Deterministic Reconciliation.
  4. Review Material Differences and any Unresolved Items.
  5. When ready, view the Signed Outcome Receipt and download the Evidence Bundle.

Supported Source Inputs

  • Form 1099-DA (CSV or JSON)
  • Koinly Capital Gains Report (CSV)
  • VaultBasis Normalized CSV

See Scope & Limitations ↗ for the full list of supported formats and known limitations.

Understanding Outcome States

  • MATCHED — All material differences resolved within declared tolerances.
  • UNMATCHED — One or more material differences not resolved.
  • UNRECONCILED — Reconciliation not yet run or data incomplete.

Unresolved items are never assumed as zero. They remain explicitly recorded in the Outcome Receipt.

Understanding the Outcome Receipt

The Outcome Receipt is a signed JSON document recording the declared reconciliation outcome. It can be verified locally using the Offline Verifier, or independently via the Independent Web Verifier ↗ without contacting VaultBasis.

Signature verification confirms the receipt has not been changed since signing. It does not assess tax correctness or constitute a professional opinion.

Troubleshooting

  • File not accepted — Check the file is a supported format and not password-protected.
  • Unresolved items remain after reconciliation — This is the intended behaviour for facts that cannot be determined from available source data.
  • Receipt signature invalid on verifier — The receipt file may have been modified after signing. Use the original downloaded file.
