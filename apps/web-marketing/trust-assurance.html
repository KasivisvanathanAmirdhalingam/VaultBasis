How VaultBasis Protects Your Data

Client case data does not need to be uploaded to VaultBasis to reconcile or verify a case.

Local Evidence Processing

Client CSV files, Form 1099-DA imports, and reconciliation calculations execute entirely within the local VaultBasis process on your computer. Case records stay on your computer.

Scope & Limitations ↗

Strict Loopback Boundary

The local runtime binds strictly to loopback (127.0.0.1) and does not require outbound network access to perform reconciliation or export evidence.

Privacy-Safe Support

Support diagnostics strip and sanitize all taxpayer information, file contents, and sensitive records before packaging, ensuring client confidential data is never shared.

Local Cryptographic Signing

Evidence Receipts are signed using a locally generated installation key stored securely on your device. Private keys never leave your machine.

How Downloads Are Verified

Every official VaultBasis release is cryptographically signed, notarized, and hashed at build time.

macOS Notarization & Developer ID

macOS binaries are signed with an Apple Developer ID Application certificate and notarized by Apple's automated notary service with hardened runtime enabled.

Windows Authenticode Signature

Windows binaries are signed with an Authenticode digital certificate and timestamped via RFC 3161 timestamping authority.

Immutable Release Digests

Every official distribution artifact carries a published SHA-256 digest recorded in the canonical release manifest.

Security Vulnerability Reporting

Security concerns or vulnerability disclosures are handled with highest priority.

What Runs on Your Computer & Network Architecture

VaultBasis operates across three separate planes to maintain strict security boundaries.

PlaneDescription
Local Edge (Your Computer) Processes client files, performs deterministic reconciliation, persists case history, and produces signed Evidence Receipts. Binds strictly to 127.0.0.1.
Marketing & License Provisioning Public website hosted on Vercel handling plan requests and delivering authorized software download links. Separate from local processing.
Independent Verifier Browser-based verification engine running 100% client-side via WebCrypto. Does not transmit receipt files or data to any server.

Independent Verification

A VaultBasis Evidence Receipt lets you independently verify that exported evidence has not been altered.

Independent Receipt Verification

Evidence Receipts can be independently verified offline or via the hosted web verifier. Verification operates entirely client-side without transmitting receipt contents to a server.

Enterprise IT Deployment & Security Profile

Information for Enterprise IT Administrators, CISO teams, and security reviewers evaluating VaultBasis on firm-managed endpoints.

Local Endpoint Architecture

VaultBasis binds strictly to 127.0.0.1 using standard user space privileges. Zero administrator/root elevation is required, and zero persistent background daemons are installed.

Zero Runtime Case Egress

Client transaction rows, Form 1099-DA imports, and tax-basis computations remain entirely on the local device. No taxpayer data or wallet information is ever transmitted to external servers.

Enterprise Durability

Local state is stored in SQLite using Write-Ahead Logging (WAL) with PRAGMA synchronous = FULL for enterprise-grade transactional resilience and crash recovery.

Governance

Specification, versioning, and change control for the VaultBasis evidence system.

  • Semantic specificationEvidence Contract v0.1 defines the receipt structure, outcome states, and signing algorithm. The specification is publicly available.
  • VersioningThe evidence contract is explicitly versioned. Changes require a version increment. Receipts declare their contract version so verifiers can apply the correct rules.
  • Release qualificationDistribution candidates undergo automated integrity, regression, and packaging checks before controlled release. Artifacts not passing qualification are not distributed.
  • Change controlChanges to the deterministic computation are evidence-controlled and tracked. The published specification and test vectors are updated with each version increment.
