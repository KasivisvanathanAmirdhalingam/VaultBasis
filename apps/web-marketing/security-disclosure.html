Security Disclosure

Design-Partner Preview — coordinated disclosure requested. No bounty program. No guaranteed response SLA.

How to Report

If you believe you have found a security vulnerability in VaultBasis Edge or vaultbasis.com, please report it by email before any public disclosure:

Email: security@vaultbasis.com

Please include:

  • A description of the vulnerability and the component affected
  • Steps to reproduce the issue
  • The potential impact as you understand it
  • Any supporting evidence (screenshots, logs, proof-of-concept where safe to share)
Do not include taxpayer data, source evidence files, or other sensitive financial information in security reports. Describe the vulnerability using only the technical information needed to understand and reproduce it.

Coordinated Disclosure

VaultBasis requests coordinated disclosure: please allow a reasonable period to investigate and address a reported vulnerability before public disclosure. We will aim to acknowledge receipt of your report promptly and to keep you informed of progress.

VaultBasis is in a controlled design-partner preview phase. No guaranteed response or resolution timeline is offered beyond best-effort handling. This will be formalized before any commercial release.

Scope

In scope for reports during the preview phase:

  • VaultBasis Edge local application (authentication, local data handling, signing)
  • vaultbasis.com website and API endpoints (entitlement provisioning, download authorization)
  • Outcome Receipt verification logic

Out of scope:

  • Vercel platform infrastructure (report directly to Vercel)
  • Social engineering or physical security
  • Issues already documented in the public Scope & Limitations

Preview Status

VaultBasis is pre-commercial software in a controlled evaluation phase. Security findings are taken seriously and contribute directly to qualification for practitioner release. There is no bug bounty program at this stage.
