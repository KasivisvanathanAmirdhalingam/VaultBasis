About VaultBasis

Independent Evidence Assurance

An independent evidence-assurance system for reconciling supported digital-asset broker and tax-ledger outcomes.

What VaultBasis Is

VaultBasis is an independent evidence-assurance system for reconciling supported digital-asset broker and tax-ledger outcomes. VaultBasis deterministically compares declared information sources, identifies agreements, differences, and unresolved information, and produces a signed Outcome Receipt that any reviewer can independently verify.

Why It Exists

Tax software produces tax-ledger outcomes. Brokers produce broker reporting information. These can differ. VaultBasis independently evaluates whether declared outcomes agree, differ, or contain unresolved information — without replacing the practitioner's professional judgment or deciding which source is legally correct.

Current Product Status

Design-Partner Preview

VaultBasis is currently available to invited design partners for evaluation using supported sample data. This is a controlled evaluation release, not a production service.

Operating Principles

  • D
    Deterministic Outcomes are computed under fixed published rules. The same inputs always produce the same output.
  • E
    Evidence-preserving Source information is hashed and traceable. Provenance references connect each outcome item to its source evidence.
  • U
    Uncertainty-preserving Missing information is flagged as unresolved, never assumed. VaultBasis never substitutes a default value for missing evidence.
  • V
    Independently verifiable Any reviewer can verify a signed receipt without VaultBasis, using the public Web Verifier or the published specification.
  • P
    Practitioner-controlled The practitioner determines professional interpretation. VaultBasis provides the comparison; it does not determine the appropriate response.

What VaultBasis Is Not

  • Not tax preparation software
  • Not a filing service
  • Not legal or tax advice
  • Not a determination of tax correctness
  • Not an IRS or government authority
