Architecture Category

Why Independently Reconcile?

Tax software and broker reporting systems each produce information used in the tax workflow. VaultBasis is deliberately separate from both. It independently compares supported information under declared deterministic rules, without deciding which source is legally or factually correct.

1

Separate Evaluator

The system producing a tax-ledger outcome is not independent of that outcome. VaultBasis provides a separate deterministic comparison against supported broker information.

2

Visible Uncertainty

When source data contains gaps or missing dates, VaultBasis preserves them as unresolved facts rather than inventing assumptions.

3

Portable Evidence Artifact

Produces a signed Outcome Receipt that can be independently checked by reviewers without the VaultBasis Edge runtime.

Evaluation Scope

Canonical Evaluation Boundary

VaultBasis enforces an unmistakable boundary between deterministic machine reconciliation and the filing practitioner's professional tax judgment.

✓ WHAT VAULTBASIS DETERMINES
✗ WHAT VAULTBASIS DOES NOT DETERMINE

Source Agreement

Whether supported information from two declared sources agrees under the declared reconciliation semantics.

Tax Correctness

VaultBasis does not determine whether a taxpayer's tax position is legally correct, optimal, or acceptable to the IRS.

Declared Differences

Surfaces exact observed differences in proceeds, cost basis, or dates without deciding which source is correct.

Legal Compliance

VaultBasis does not determine compliance with federal, state, or other applicable tax law.

Unresolved Information

Flags missing facts without inventing or substituting default dates, zero values, or arbitrary pricing assumptions.

Source Truth

A successful comparison does not establish that either source file is authentic, complete, or factually accurate.

Payload Integrity & Signature

Verifies that an Outcome Receipt has not been changed since it was signed, and confirms the signature is valid for the key that produced it.

Professional Judgment

VaultBasis does not replace the practitioner's professional judgment, due diligence, or responsibility for the resulting tax position or filing.

Deployment Boundary

Local-First Evidence Processing

VaultBasis Edge is designed for local evidence processing. Source evidence used in reconciliation is processed within the declared local application boundary. Website, access-request, and distribution interactions are separate from the local Edge processing boundary. See Scope & Limitations for tested network behavior, storage boundaries, and known limitations.

Local Processing

Supported evidence intake and reconciliation execute entirely within the local VaultBasis Edge process.

Local Signing

Outcome Receipts are signed using a locally generated persistent Ed25519 installation key.

Clean-Machine Verification

The offline verifier can validate supported Outcome Receipts without a network connection or VaultBasis account. The hosted Web Verifier provides browser-based verification using WebCrypto.
