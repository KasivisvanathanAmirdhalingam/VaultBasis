VaultBasis Edge

Design Partner Preview (Release Candidate 1) — Quick Start Guide

1 What to Expect (Zero Data Egress)

VaultBasis is not a traditional cloud application. It is a local Edge Daemon.

Because you are processing highly sensitive financial ledgers (Form 1099-DAs, tax lot histories), the VaultBasis Edge application runs entirely inside your local machine. It never transmits your transaction data or API keys to our servers. The output is a cryptographically signed "Outcome Receipt" that proves you ran the software locally.

2 Launching the Application

The file you extracted is a native, pre-compiled terminal executable. Because this is an early Design Partner preview, it is not yet published on official app stores, meaning your operating system's security gatekeeper will intentionally block it at first.

🍎 macOS Users (Gatekeeper Bypass)

If you double-click the file and see an error saying "Apple could not verify...":

  • Click Done on the popup.
  • Open your Mac's System Settings.
  • Navigate to Privacy & Security.
  • Scroll down to the "Security" section and click the "Open Anyway" button next to VaultBasis.
  • Enter your Mac password. The application will instantly launch.

🪟 Windows Users (SmartScreen Bypass)

If you double-click the .exe and see a blue "Windows protected your PC" screen:

  • Click the underlined "More info" text.
  • Click the "Run anyway" button that appears at the bottom.

3 Operating the Dashboard

Once successfully launched, a black terminal window will open on your screen showing the boot sequence. After 1-2 seconds, it will automatically open your default web browser (Chrome, Safari, Edge) to:

VaultBasis Edge active on http://127.0.0.1:8000

This is your local Command Center. From here you can:

  • Import Ledgers: Drag and drop your Koinly or generic CSV tax ledgers.
  • Simulate Audits: Run the deterministic reconciliation engine to verify standard compliance.
  • Generate Evidence: Cryptographically sign the outputs into an Evidence Contract (Outcome Receipt).

Note: Do not close the black terminal window while using the dashboard in your browser. Closing the terminal will shut down the local server.
