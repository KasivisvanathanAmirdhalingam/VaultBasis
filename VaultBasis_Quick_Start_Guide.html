1 What this application does

VaultBasis runs entirely on your computer. It compares broker records with your tax ledger, identifies what agrees, what differs, and what is missing, then produces a signed receipt you can share with your reviewer.

During the reconciliation workflow, your files are processed on your own computer — your browser talks to VaultBasis at a local address on your machine, not to a cloud service. See the MMP-1 Local Processing Test Summary for the exact tested boundary.

What to expect: After launching, a small window will briefly appear, then your web browser will automatically open to http://127.0.0.1:8000 — your local dashboard. Keep the small window open while working; closing it shuts down the application.

2 First launch — approve the application

Because this is a preview build distributed outside the Mac App Store or Microsoft Store, your operating system will block it the first time. This is expected and is straightforward to resolve.

Which macOS version do you have?
Click the Apple menu (top-left) → About This Mac. The version number appears next to "macOS". Select your version below.
Select your macOS version:
macOS 15 Sequoia — "Open Anyway" does not appear for this type of file.
Apple changed Gatekeeper in Sequoia. The "Open Anyway" button in System Settings is only shown for installer packages, not for standalone executables like this one. You must use the Terminal method below — it takes about 30 seconds.

Option A — One-click script (recommended)

A file called launch_vaultbasis.command is included in the download. Double-click it. If a security prompt appears, right-click it and choose Open. This script handles everything automatically.

If the script itself is also blocked, use Option B below.

Option B — Terminal (always works)

  1. Open Terminal (press ⌘ Space, type Terminal, press Enter).
  2. Type the following exactly, then press Enter. When prompted, enter your Mac password (nothing will appear as you type — that is normal):
$ xattr -d com.apple.quarantine ~/Downloads/VaultBasis-Edge-v0.1.0-preview-macOS
  1. If you see No such xattr, the file is already cleared — skip to step 4.
  2. Now double-click VaultBasis-Edge-v0.1.0-preview-macOS in Finder. It will launch.
Tip: If you extracted the download to a different folder, replace ~/Downloads/ in the command above with the path to that folder. You can drag the file from Finder into the Terminal window to paste the full path automatically.

Option A — Right-click method (easiest)

  1. In Finder, right-click (or Control-click) the file VaultBasis-Edge-v0.1.0-preview-macOS.
  2. Choose Open from the menu.
  3. A dialog appears saying Apple cannot verify the developer. Click Open in that dialog.
  4. Enter your Mac password if prompted. The application launches.
If right-click → Open does not show a dialog (it just blocks): Try the System Settings method below, or use the Terminal method from the Sequoia tab — it works on all versions.

Option B — System Settings

  1. Double-click the file. You will see a security error. Click Done.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the Security section. You will see a message about VaultBasis with an "Open Anyway" button.
  4. Click Open Anyway, enter your password, then double-click the file again.
Important: The "Open Anyway" button disappears after about one hour. If you do not see it, double-click the file again to re-trigger the block, then immediately check System Settings.

Option A — Right-click method

  1. In Finder, right-click (or Control-click) the file VaultBasis-Edge-v0.1.0-preview-macOS.
  2. Choose Open from the menu.
  3. A dialog appears. Click Open.

Option B — System Settings

  1. Double-click the file. You will see a security warning. Click OK.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the Security section. Click Open Anyway next to the VaultBasis message.
  4. Enter your password and double-click the file again.

System Preferences method

  1. Double-click the file. You will see a security warning. Click OK.
  2. Open System Preferences → Security & Privacy → General tab.
  3. Click the lock icon at the bottom left and enter your password to unlock.
  4. Click Open Anyway next to the VaultBasis message.
  5. Double-click the file again. It will launch.
Note: On macOS 12 (Monterey) and earlier, System Preferences is the name of what was renamed to System Settings in macOS 13.
  1. Double-click VaultBasis-Edge.exe. A blue screen titled "Windows protected your PC" will appear.
  2. Click the "More info" link (underlined, in the middle of the screen).
  3. A "Run anyway" button will appear at the bottom. Click it.
  4. VaultBasis will launch. You will only need to do this once.
Why does this happen? Windows SmartScreen flags any application that has not yet built up a reputation in Microsoft's system. This is standard for early-access software distributed outside the Microsoft Store and does not indicate a problem with the file.

3 Using the dashboard

After launching, a small terminal window will open briefly, then your default browser will open automatically to your local dashboard. If it does not open after 5 seconds, go to:

http://127.0.0.1:8000

From the dashboard you can:

  1. Upload your files — drag and drop your broker statement and tax ledger (CSV).
  2. Run a comparison — VaultBasis checks what matches, what differs, and what cannot be resolved from the information provided.
  3. Download your receipt — a signed file is produced that records exactly what was compared and what was found. It can be verified independently.
Keep the terminal window open while you are working in the browser. Closing it stops the local application.

4 Troubleshooting

The browser does not open automatically (macOS)

Manually go to http://127.0.0.1:8000 in any browser.

The file still will not open after following the steps above

Use the Terminal command from the macOS Sequoia section — it works on all macOS versions (13, 14, and 15):

$ xattr -d com.apple.quarantine ~/Downloads/VaultBasis-Edge-v0.1.0-preview-macOS

The terminal window closes immediately (macOS)

  1. The file may not have execute permission. Open Terminal and run:
$ chmod +x ~/Downloads/VaultBasis-Edge-v0.1.0-preview-macOS && ~/Downloads/VaultBasis-Edge-v0.1.0-preview-macOS
